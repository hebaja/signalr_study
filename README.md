# signalr

Study project for learning ASP.NET Core + SignalR. The goal is to build a basic chat app using SignalR for real-time communication.

## Run

```bash
dotnet run
```

Then open `http://localhost:5000` (or the port printed in output).

If the .NET 10 prune-metadata error returns:

```bash
dotnet run -p:AllowMissingPrunePackageData=true
```
